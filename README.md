# Mafatlal MedFits — E-commerce Customizations

**Live site:** [mafatlalmedfits.com](https://www.mafatlalmedfits.com/)

Custom sections built for this e-commerce storefront — things not
available out of the box in the base theme. Each one is documented as a
mini case study with code and screenshots.

Liquid, theme editor schema (JSON settings/blocks), HTML, CSS (custom
properties, keyframe animation), vanilla JavaScript.
